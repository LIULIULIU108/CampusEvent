## 6. 缺陷与修复记录

| 编号 | 问题/复现 | 原因 | 修复与验证 |
| --- | --- | --- | --- |
| D-01 | Windows 启动报 `ZoneInfoNotFoundError` | 缺少 IANA 时区库 | requirements 增加 `tzdata` |
| D-02 | 重复/并发报名可能产生两条有效报名 | 应用层先查后插有竞态 | 部分唯一索引 + `BEGIN IMMEDIATE`；测试通过 |
| D-03 | 通知失败可能影响报名 | 通知与报名耦合 | 提交后发布 + `notification_attempt` 留痕；测试通过 |
| D-04 | 验收脚本把 flash 活动名当表格行 | 验收脚本正则起点错误 | 从 `title-cell` 匹配；重跑 C1—C10 通过 |
| D-05 | 批准可能超容量/重复批准 | 审批未在写事务内复查 | `BEGIN IMMEDIATE` + 条件 UPDATE；测试通过 |
| D-06 | 直接改 CHECK 无法兼容旧库 | SQLite 不支持修改 CHECK | v1→v2 重建 student/activity；迁移测试验证数据/外键/序列 |
| D-07 | 邮件失败会随观察者事务回滚而丢失记录 | 失败记录写在被回滚事务中 | `EventPublisher.on_error()` 在回滚后写 `email_outbox=FAILED`；CR2-03 测试通过 |
| D-08 | 待审核事件也发邮件 | 邮件观察者未过滤事件 | `supports()` 只订阅通过/拒绝；CR2-01/CR2-02 测试通过 |

## 7. 覆盖边界与已知限制

已覆盖：三类报名、年级 1—4、满额、重复、取消、审批、审批满额、开始时间、通知失败、事件去重、邮件失败、迁移、持久化、权限、校验。

未覆盖/限制：

- **真实 SMTP/短信**：CR-02 使用 MockEmailSender，不接真实邮件服务器；收件人为 `学号@mock.campus.local`。
- **年级范围固定**：仅大二/大三，未做按活动配置。
- CSRF：演示版未实现 token；生产化需补。
- 高并发：SQLite 单写者；未压测。
- 分页/大数据量：未实现。
- 浏览器兼容矩阵：仅本机 Edge 验证。
